# こころの作戦カード — 体験モック

会話・自問自答で対処カードを発見し、選択の結果を比較する2つの架空ストーリー。

## 起動
`python -m http.server 4173 --directory dist`

依存なしの静的サイト。状態はメモリ内のみで、個人情報入力・成績保存・通信を伴わない。

## 構造
- dist/engine.mjs: ストーリー状態・カード定義・分岐・効果・フリー行動。DOM非依存。
- dist/app.js: 画面、ダイアログ、履歴、選び直し、任意のWebMCP。
- dist/style.css: レスポンシブ、日本語フォント、色以外での状態表示。
- test.mjs: 分岐、資源境界、文脈依存効果、安全行動・フリー行動のチェック。

## 画面構成（TRPG風）
教師がゲームマスターとして口頭で補足できることを前提にしつつ、必要な情報はアプリ内で完結させる。

- 左: システム系UI（ストーリー・目的・作戦ノート）
- 中央: 地の文と、他キャラのセリフ・様子、自分のこころの声
- 右: 「自分に問う」「話す・相談する」と、いつでも選べる行動
- 下: 扇形に持つ手札と、資源アイコン（手札枚数・行動力・こころの余裕・いいなと思う人）

## 設計判断
- 合計点や唯一の最適エンディングを設けない。目的によって進捗が変わる。
- 信頼を架空の精密数値にせず、会話や約束の記録として示す。「いいなと思う人」は相手との関係の記録ではなく、向社会的な選択を促すための簡単な人数パラメータ。
- 「いいなと思う人」（0-5、初期1）: 話す・相談する・伝える・協力する・きき返す・大人に相談など、他者と関わる行動（カードの `bond` フラグ）で増える。一人でやる行動・自問・休息では増えない。まわりにぶつけるマイナスカード（文句をいう・やつあたりする）だけが減らす。
- 全カードは行動力コスト（0-5）とストレスコスト（0-5、カードの `strain`）を持つ。動くことは心をすり減らす。
- ストレス5以上（気持ちがいっぱい）では手札が赤いマイナスカードに入れ替わる。文句をいう・失敗する・やつあたりする・泣く・さぼる——場面ごと各1回で、出すとストレスが回復する。気まずいやり取りが残るものは「いいなと思う人」が減る。回復はマイナスカード以外（少し休む・離れる・大人に相談）でも可能。
- ストレス・余力は架空キャラクターのモデルであり、児童の測定値ではない。
- 基本カードの選択は場面を進める。探索は各質問1回、休憩による回復は各場面1回。
- 「きき返す」「何もしない」は場面ごと各1回のフリー行動で、カードにはしない（いつでも選べるものは手札にしない、というメモの反映）。
- ストレスが5以上（気持ちがいっぱい）では「話す・相談する」「自分に問う」は使えない。まず休む・離れて落ち着く — 焦っている時に深い話はできない、というメモの反映。
- 休憩・離脱・援助は手札・余力・気持ちの状態に依存しない。離脱や援助で振り返りに移る。
- ふりかえりでは「いいなと思う人」の数と「見つけた作戦」の数（考え方が広がったか）を高く評価する。合計点や順位にはしない。
- 練習カードは運動会の負担理由（動き・他者評価・音）で効果が変わる。
- 会話の結果は固定分岐。相手の反応が常に思いどおりになる一般則を示すものではない。
- 学習効果は未検証。正式版には児童・支援者との試遊、文章や読み仮名の調整が必要。
